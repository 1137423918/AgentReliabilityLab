# 固定资料集合与检索诊断

A/B清单只有来源URL、版本、路径、SHA-256和题名，没有附模型权重或第三方原文。要重放，按清单的不可变GitHub链接取得原始文件，放在同目录`sources/`对应路径；先核对SHA-256，再运行索引。B只替换项目README、加入依赖审查工作台文档、移除历史工具基线，历史来源仍保留在旧代索引中。

LS-DETR来源是仓库README和BibTeX，**不是完整论文**；检索问题与指定来源不进入索引。24条为操作者预先编写的已知来源导航诊断，不是盲测问答集。资料版本早于研究检索模块本身，避免把本轮检索结论写回被测资料。

也可按相同JSON结构使用自己的可信UTF-8资料；`path`由操作者明确指定，本工具不会抓取网页或执行文档内容。公开示例的24条问题用于固定诊断，不代表任意新资料的金标。
