# 持久批量检索输入示例

`questions.jsonl`是本次三条新查询的固定输入，不含相关性标签或期望答案。它们用于检查真实CPU检索的进程恢复，不是问答评测集。

按[使用说明](../../docs/research-batch-recovery.md)选择自己的已导入资料库、新输出及新任务目录。首次指定`--state-dir`与所需固定尝试额度；恢复只增加`--resume`，保持原输入字节及其他参数。不要将示例命令指向已关闭的实验目录。

项目实际验证沿用三篇论文的私有索引，仅执行3次新查询前向；结果片段留在私有归档，公开[执行记录](../../evidence/batch-recovery/README.md)保存计数与来源核对范围。
