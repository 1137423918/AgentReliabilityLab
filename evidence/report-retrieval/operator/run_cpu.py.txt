"""One fresh server CPU profile: fixed metadata queries and real SDK controls."""
from pathlib import Path, PurePosixPath
import hashlib
import json
import os
import shutil
import signal
import socket
import subprocess
import tarfile
import tempfile
import time
import urllib.request

OUT = Path(__file__).resolve().parent
spec = json.loads((OUT/'protocol.json').read_text())
sha = lambda p: hashlib.sha256(p.read_bytes()).hexdigest()
assert not (OUT/'run-report.json').exists()
assert sha(OUT/'run_cpu.py') == spec['controller_sha256']
assert sha(OUT/'source.tar.gz') == spec['archive_sha256']
assert sha(OUT/'exec_child.py') == spec['wrapper_sha256']
SDK = Path('[SDK_SOURCE]/extras/mcp-agent/.venv/bin/python')
CORE = Path('[CORE_PYTHON]')
RUFF = Path('[RUFF]')
assert SDK.is_file() and RUFF.is_file()
os.umask(0o077)
os.nice(19)
os.sched_setaffinity(0, sorted(os.sched_getaffinity(0))[:4])
ROOT = Path(tempfile.mkdtemp(prefix='agentlab-report-retrieval-stage63-'))
SRC = ROOT/'source'; SRC.mkdir()
parent_start = int(Path('/proc/self/stat').read_text().rsplit(')', 1)[1].split()[19])
(OUT/'location.json').write_text(json.dumps({'root': str(ROOT), 'source': str(SRC)})+'\n')
env = {k: v for k, v in os.environ.items() if k not in ['PYTHONPATH', 'LD_PRELOAD', 'LD_LIBRARY_PATH'] and not k.endswith(('_KEY', '_TOKEN'))}
env.update(CUDA_VISIBLE_DEVICES='', PYTHONDONTWRITEBYTECODE='1', OMP_NUM_THREADS='4', OPENBLAS_NUM_THREADS='4', MKL_NUM_THREADS='4', TMPDIR=str(ROOT), XDG_CACHE_HOME=str(ROOT/'cache'), HF_HUB_OFFLINE='1', TRANSFORMERS_OFFLINE='1')
report = {'terminal': False, 'protocol_sha256': sha(OUT/'protocol.json'), 'phases': [], 'new_neural_calls': 0, 'GPU_used': False}
child = server = None
known = {}
began = time.monotonic()
memory = lambda: int(next(x.split()[1] for x in Path('/proc/meminfo').read_text().splitlines() if x.startswith('MemAvailable:')))*1024


def save():
    tmp = OUT/'run-report.tmp'; tmp.write_text(json.dumps(report, indent=2)+'\n'); os.replace(tmp, OUT/'run-report.json')


def owned():
    rows = {}
    for p in Path('/proc').glob('[0-9]*'):
        try:
            if p.stat().st_uid != os.getuid(): continue
            s = (p/'stat').read_text().rsplit(')', 1)[1].split()
            rows[int(p.name)] = {'parent': int(s[1]), 'start': int(s[19]), 'state': s[0], 'rss': int(s[21])*os.sysconf('SC_PAGE_SIZE')}
        except (OSError, ValueError): pass
    ids = {p.pid for p in [child, server] if p is not None and p.poll() is None and p.pid in rows}
    ids.update(p for p, start in known.items() if p in rows and rows[p]['start'] == start)
    for _ in range(16):
        old = len(ids); ids.update(p for p, row in rows.items() if row['parent'] in ids)
        if len(ids) == old: break
    ids = {p for p in ids if rows[p]['state'] != 'Z'}
    known.update({p: rows[p]['start'] for p in ids})
    return {p: rows[p] for p in ids}


def stop():
    for sig in [signal.SIGTERM, signal.SIGKILL]:
        for pid, value in owned().items():
            if owned().get(pid, {}).get('start') == value['start']:
                try: os.kill(pid, sig)
                except ProcessLookupError: pass
        for p in [child, server]:
            if p and p.poll() is None:
                try: p.wait(timeout=3)
                except subprocess.TimeoutExpired: pass
        if not owned(): break


def argv(command):
    return [str(CORE), str(OUT/'exec_child.py'), str(os.getpid()), str(parent_start), 'cpu', *[str(x) for x in command]]


def run(name, command, cap=120, cwd=SRC):
    global child
    report['active_phase'] = name; save(); start = time.monotonic(); peak = 0
    with (OUT/(name+'.log')).open('wb') as log:
        child = subprocess.Popen(argv(command), cwd=cwd, env=env, stdout=log, stderr=subprocess.STDOUT, start_new_session=True)
        while child.poll() is None:
            rss = sum(v['rss'] for v in owned().values()); peak = max(peak, rss)
            if time.monotonic()-start > cap or time.monotonic()-began > 900 or rss > 3*2**30 or memory() < 4*2**30:
                raise RuntimeError('CPU time/memory guard: '+name)
            time.sleep(.2)
        code = child.wait()
    report['phases'].append({'name': name, 'exit_code': code, 'wall_seconds': round(time.monotonic()-start, 3), 'peak_owned_RSS_bytes': peak}); save()
    assert code == 0, name


try:
    assert memory() >= 8*2**30 and shutil.disk_usage('/tmp').free >= 2*2**30
    report['initial_memory_bytes'] = memory()
    with tarfile.open(OUT/'source.tar.gz') as archive:
        for item in archive:
            path = PurePosixPath(item.name); assert item.isfile() and not path.is_absolute() and '..' not in path.parts
            dst = SRC/item.name; dst.parent.mkdir(parents=True, exist_ok=True); dst.write_bytes(archive.extractfile(item).read())
    assert all(sha(SRC/rel) == digest for rel, digest in spec['files_sha256'].items())
    env['PYTHONPATH'] = str(SRC)
    run('format-changed', [RUFF, 'format', *spec['changed_python']])
    run('lint-changed', [RUFF, 'check', *spec['changed_python']])
    report['tested_source_sha256'] = {rel: sha(SRC/rel) for rel in spec['changed_python']}
    run('retrieval-unit-controls', [SDK, '-m', 'unittest', 'discover', '-s', 'tests', '-p', 'test_report_retrieval.py', '-v'])
    identity = "import importlib.metadata as m,json,benchmarks.llamaindex_mcp_audit as a;print(json.dumps({'adapter':a.__file__,'packages':{n:m.version(n) for n in ['mcp','llama-index-core','llama-index-workflows','openai','httpx2']}}))"
    run('runtime-identity', [SDK, '-c', identity])
    runtime = json.loads((OUT/'runtime-identity.log').read_text()); assert runtime['packages'] == spec['packages'] and Path(runtime['adapter']) == SRC/'benchmarks/llamaindex_mcp_audit.py'
    report['runtime'] = runtime
    # The judgments are never passed to the retrieval module or model adapter.
    run('metadata-diagnostics', [SDK, '-m', 'benchmarks.report_retrieval', '--root', SRC/'evidence/report-retrieval/corpus', '--manifest', SRC/'evidence/report-retrieval/corpus/catalog.json', '--cases', SRC/'benchmarks/report_retrieval_cases.json', '--output', ROOT/'diagnostics'])
    report['retrieval_summary'] = json.loads((ROOT/'diagnostics/summary.json').read_text())
    with socket.socket() as sock:
        sock.bind(('127.0.0.1', 0)); port = sock.getsockname()[1]
    server_log = (OUT/'mcp-server.log').open('wb')
    server = subprocess.Popen(argv([SDK, '-m', 'benchmarks.mcp_evidence_server', '--root', SRC/'evidence/report-retrieval/corpus', '--manifest', SRC/'evidence/report-retrieval/corpus/catalog.json', '--port', port]), cwd=SRC, env=env, stdout=server_log, stderr=subprocess.STDOUT, start_new_session=True)
    until = time.monotonic()+30
    while True:
        assert server.poll() is None, 'MCP server exited before ready'
        try:
            with urllib.request.urlopen(f'http://127.0.0.1:{port}/health', timeout=1) as response: assert json.load(response) == {'status': 'ok'}
            break
        except OSError:
            assert time.monotonic() < until, 'MCP startup timeout'
            time.sleep(.2)
    baseline = ROOT/'baseline'; shutil.copytree(SRC, baseline)
    old = (SRC/'baseline-adapter.py').read_bytes(); assert hashlib.sha256(old).hexdigest() == spec['baseline_adapter_sha256']
    (baseline/'benchmarks/llamaindex_mcp_audit.py').write_bytes(old)
    for profile, code in [('baseline', baseline), ('default-candidate', SRC)]:
        run(profile+'-MCP-controls', [SDK, '-m', 'benchmarks.mcp_agent_controls', '--code', SRC/'evidence/report-retrieval', '--state', ROOT/(profile+'-controls'), '--mcp-url', f'http://127.0.0.1:{port}/mcp', '--owner', sha(OUT/'protocol.json')], 180, cwd=code)
    a = json.loads((ROOT/'baseline-controls/report.json').read_text()); b = json.loads((ROOT/'default-candidate-controls/report.json').read_text())
    assert [v['model_request_sha256'] for v in a['cases']] == [v['model_request_sha256'] for v in b['cases']]
    report['default_request_bodies_identical'] = True
    report['default_model_POSTs_per_profile'] = sum(v['fake_model_posts'] for v in a['cases'])
    run('ranked-MCP-controls', [SDK, '-m', 'benchmarks.report_retrieval_controls', '--code', SRC/'evidence/report-retrieval', '--state', ROOT/'ranked-controls', '--mcp-url', f'http://127.0.0.1:{port}/mcp', '--owner', sha(OUT/'protocol.json')], 180)
    report['ranked_controls'] = json.loads((ROOT/'ranked-controls/report.json').read_text())
    report['ready'] = True
except BaseException as error:
    report['error'] = {'type': type(error).__name__, 'message': str(error)[:500]}
finally:
    stop()
    if server is not None:
        server_log.close()
        report['MCP_server_exit_code'] = server.returncode
        with socket.socket() as sock: report['MCP_port_closed'] = sock.connect_ex(('127.0.0.1', port)) != 0
    report.update(terminal=True, owned_after=len(owned()), wall_seconds=round(time.monotonic()-began, 3))
    report['final_source_sha256'] = {rel: sha(SRC/rel) for rel in spec['changed_python'] if (SRC/rel).is_file()}
    report['unformatted_inputs_unchanged'] = all((SRC/rel).is_file() and sha(SRC/rel) == digest for rel, digest in spec['files_sha256'].items() if rel not in spec['changed_python'])
    save(); print(json.dumps(report), flush=True)
raise SystemExit(0 if report.get('ready') and not report.get('error') and not report['owned_after'] and report.get('MCP_port_closed') and report['unformatted_inputs_unchanged'] else 2)
