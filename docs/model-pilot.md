# 本地模型维护任务试验

状态：接入与验收准备已验证，模型推理尚未运行。运行器在启动检查发现没有空闲 GPU 后退出，没有加载模型。

## 任务与验收

任务固定到 Deep Agents `744a797e3b9495539ca35571eeffd112a205f5c8`，允许编辑生产路径工具与其测试文件。模型接收问题现象，不接收脚本编辑计划或参考补丁。

验收依次检查：导入源码确实来自工作区、上游官方测试、操作者在任务定义中嵌入的 28 个路径契约。最后一组验收位于模型不可编辑的任务定义中。原始源码通过原有 113 条官方测试，但在独立契约中只有 22 条通过；操作者参考补丁通过 119 条官方测试与全部 28 条契约。

这是公开已知问题的工程试验，不是排除训练数据污染的隐藏基准。参考补丁只用于验收自检，不属于模型成果。

## 已完成的接入验证

Linux 服务器上完整 26 条项目测试通过，其中 5 条使用明确的假 HTTP 服务验证传输与试验编排：真实请求中的工具 schema、工具结果回传、补丁验证、完成后重放不再请求模型、请求输出上限与 seed、非回环地址拒绝、服务错误和超时不自动重试。

正常/恢复试验的编排还覆盖一个边界：最后一个工具已经完成时，恢复后模型可以直接结束，不应被强制要求额外调用一次工具。这项测试仍是编排验证，不是神经模型推理。

## 模型与预算

首个预设采用 `Qwen/Qwen3-4B-Instruct-2507`，revision `cdbee75f17c01a7cc42f958dc650907174af0554`，作为兼容现有 vLLM 0.11 环境的小模型工程基线。12 个模型文件共 8,060,915,998 字节，使用官方固定版本的文件大小、Git blob SHA-1 或 LFS SHA-256 校验；镜像只用于传输。没有把权重提交到代码仓库。

任务固定贪心解码、seed 42、每请求最多 1536 个输出 token、请求超时 180 秒、不自动重试、持久化图步数上限 40。试验入口对每个场景设置 600 秒墙钟上限。这些是不同维度的限制，不构成总 token 或费用预算。

本轮为纯文本输入。预设服务使用本机回环接口、单张空闲设备、单并发和受限上下文；实际推理服务启动与模型效果尚待 GPU 可用后验证。

## 复现入口

先准备原项目文档所述的固定 SDK 验证环境，放入 `PATH`。启动固定版本权重的 OpenAI 兼容服务，开放工具调用解析，并将服务模型别名设为 `agentlab-qwen3-4b`。接入信息只通过运行时环境提供。

```sh
uv sync --extra local-model --frozen
export AGENT_LAB_MODEL_URL=http://127.0.0.1:8000/v1
# 若服务有验证密钥，通过 AGENT_LAB_MODEL_KEY 提供，不写进任务文件。
uv run --extra local-model python benchmarks/model_pilot.py \
  --repo /path/to/deepagents \
  --task tasks/deepagents-path-model-baseline.json \
  --output runs/model-pilot-001 --case-deadline-seconds 600
```

入口预先定义正常运行与检查点中断后恢复两个场景，保留失败结果与日志。返回码表示试验编排结束；实际成果以报告中的 `verified_patch`、`verified_trials` 和逐条测试结果判断。两次试验围绕同一个任务，不应换算成通用任务成功率。

当前模型只在虚拟文件区执行编辑；验证命令在模型阶段结束后由运行器执行，测试失败不会自动反馈给模型继续修补。完整检查点与会话保持私有，对外仅发布经过检查的结果。
