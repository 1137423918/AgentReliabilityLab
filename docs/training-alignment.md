# 固定推理文本的监督审计

三组生成对照已经完成：base 118/199、Full 107/199、Mixed 105/199，微调后的 clean correct 均下降。本阶段追查训练目标与调用行为的关系，读取全部 597 条已保存结果和原训练数据，**没有新增模型调用、优化器更新或重新评分**。旧账本中两次历史未知仍占额度。

## 训练标签中有多少固定文本

固定版本的上游转换脚本为工具调用和直接回答分别添加一段固定的 `<think>` 文本。通过 AST 读取这两个字符串，不导入转换脚本；用固定 tokenizer 的字符偏移重新构建原始序列，并逐 token 检查其与缓存输入、标签完全一致。

| 数据 | 行数 | 原监督标签 | 固定文本标签 | 保留标签 |
| --- | ---: | ---: | ---: | ---: |
| Full 训练 | 3,700 | 335,822 | 56,071（16.70%） | 279,751 |
| Mixed 训练 | 3,700 | 336,489 | 56,071（16.66%） | 280,418 |
| clean 开发 | 197 | 16,220 | 2,991 | 13,229 |
| 原扰动验证 | 79 | 6,887 | 1,187 | 5,700 |

Full 和 Mixed 均有 3,253 条工具调用目标、447 条直接回答目标；这些是目标格式统计。没有删除直接回答样本，也没有修改答案、工具名称、参数、输入或 EOS。

准备的消融只将**完全位于开头、与上游固定文字精确匹配的推理正文内**的标签设为 `-100`。保留标签边界两侧的 token、标签本身、可变推理、后文中的相同字符串和实际回答。跨字符边界的 token 不屏蔽。

原 Full 32 步调度的输入、顺序和片段边界保持不变：774 个片段、573,843 个输入 token 暴露位置，监督标签由 65,536 变为 54,187；没有零有效标签片段。Mixed 的对应计数为 772 个片段、537,483 个输入位置、54,219 个有效标签。**这些是准备数据的计数，尚未用新掩码训练。**

若运行配对消融，需要重新训练同条件的未屏蔽参考组，并在每次更新中用该步实际有效标签数归一化损失；不能继续把屏蔽后的损失除以 2,048。相同输入暴露也不保证输出投影等计算量完全一致。原 Full 训练的核验缺口仍保留，不能把独立复训用作覆盖原失败的重试。

## 已保存生成中的行为变化

以下只使用原结果中已保存的解析调用和官方评分；标记通过字符串存在性统计，不重新解析或评分。

| 全部 199 例 | Base | Full | Mixed |
| --- | ---: | ---: | ---: |
| 已保存官方 correct | 118 | 107 | 105 |
| 未解析出工具调用 | 23 | 34 | 39 |
| 包含已发布固定推理文本 | 0 | 34 | 41 |

API-Bank 的 74 例中，correct 为 42 / 32 / 30，未解析出调用为 13 / 21 / 26。与 Base 同例配对后：

| API-Bank 配对变化 | Full 对 Base | Mixed 对 Base |
| --- | ---: | ---: |
| 原来正确、现在错误 | 17 | 20 |
| 原来错误、现在正确 | 7 | 8 |
| 失去正确且现在无调用 | 9 | 14 |
| 失去正确且含固定推理文本 | 7 | 11 |

这些关联支持继续检验监督目标，但**不能证明固定文本导致退化**。没有调用不等于语义上的拒绝；包含 `<response>` 也不代表回答一定正确。无工具任务需要保留，不能只靠提高调用次数评价方法。全部已知 199 例已经用于诊断，后续只能作为开发证据，不再当作未观察的测试集。
