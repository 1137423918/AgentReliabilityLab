# 固定正文损失屏蔽的配对试验

本页记录独立的新试验，不覆盖原Full训练的核验失败。方法在首次读取新BFCL参考答案前已[声明](../evidence/bfcl-transfer-scoring/v1/scoring-intent.json)。**两组均已完成32次更新、1,333次逻辑前向及完整最终核验，控制器退出0。** 尚未进行新的模型生成评测，不能据此声称工具调用效果提升。

两组均从同一Qwen2.5-3B-Instruct基座重新初始化LoRA，在同一张新准入的RTX3090上使用相同Full输入、顺序和32步调度。只改变固定推理正文是否计入损失，正常无需工具样本、标签和回答内容都保留；不读取BFCL参考答案来训练。

| 固定条件或计数 | Reference | Masked |
| --- | ---: | ---: |
| 优化器更新数 | 32 | 32 |
| 训练反向片段 | 774 | 774 |
| 输入token暴露位置 | 573,843 | 573,843 |
| 实际监督标签 | 65,536 | 54,187 |
| 已完成逻辑前向（含核验） | 1,333 | 1,333 |

按每步实际有效标签数归一化累积的CE总和。屏蔽组每步有效标签不同，不能继续除以固定2,048，也不能按片段数平均。保留完整因果上下文，只选择有效标签前一位置的logits；相同输入暴露不保证词表投影成本或FLOPs完全一致。

模型、LoRA与AdamW配方沿用[原试验](lora-pilot.md)：FP16/原生SDPA、TF32关闭，seed42，q/v的rank8、alpha16、dropout0，训练参数FP32，学习率2e-4、裁剪1.0、GradScaler1024，固定最终step32，不按分数挑选检查点。新入口单独保存，原训练入口及旧结果不改。

CPU已通过6项数值控制：内部掩码的因果位置、空片段拒绝、目标篡改拒绝、选择位置与完整标准损失及梯度一致，以及不同有效标签数片段的整步归一化；同时验证全部3,700行原始/屏蔽输入与真实32步调度。旧生成账本、数据和掩码文件哈希不变，CUDA未初始化。此预检没有载入3B权重、执行模型训练或分配生成请求。

GPU阶段已通过真实模型的未屏蔽/屏蔽标准损失canary、初始零LoRA与参数指纹、逐步梯度和优化器更新、最终冻结参数哈希、禁用适配器及检查点重载。两组训练前的基座和LoRA指纹相同，197条开发与79条原验证的逐例顺序、标签数一致。

独立训练预算两组共2,666次逻辑前向、64次更新，全部预留并完成；未知前向、未知更新和异常日志行均为零。每组8/16/24/32步四个检查点的清单已核对；最终检查点另外复制到服务器私有稳定目录并逐文件验哈希，未公开权重或优化器状态。逻辑前向不另外计算梯度检查点内部的重算，不等于总物理前向或FLOPs。

没有自动重试或训练恢复。本次成功是独立配对试验的结果，不会把旧Full原运行补判通过；跨运行训练权重也不保证逐位一致。

资源准入与监控由单独控制器执行：相同物理GPU、两次新鲜空卡样本、UUID建议锁及再次检查；显存22,528MiB、进程RSS24GiB、宿主内存余量和超时保护。建议锁不构成调度器独占，发现其他计算进程时只停止自有任务。

## 实际损失与边界

两组使用相同的未屏蔽整段assistant目标评测，包含固定正文、标签和实际回答：

| Token加权NLL | 训练前，两组相同 | Reference step32 | Masked step32 |
| --- | ---: | ---: | ---: |
| clean开发，197条／16,220标签 | 1.489357 | 0.277460 | 0.688947 |
| 原扰动验证，79条／6,887标签 | 1.442288 | 0.297588 | 0.671653 |

Masked的整段答案NLL比Reference高。该指标包含训练时被屏蔽的正文，当前没有逐token损失分解，不能直接把差异归因于某一部分，也不能用它代替自由生成的工具调用成功率。两组均为单种子、小预算、固定32步试验，不是完整训练周期或鲁棒性提升证明。

整场1,005.314秒；Reference阶段461.856秒、Masked阶段443.303秒。这些是本次运行耗时，不构成速度收益结论。自有进程和GPU上下文已清理，所有原数据、掩码和旧生成账本保持原哈希；新试验没有未知调用，旧账本两次未知仍扣额。

250条迁移输入的[评分链路](bfcl-transfer-scoring.md)已准备好，但**尚未分配或执行新生成评测**。下一步在固定输入和新声明的推理预算下比较base／新Reference32／新Masked32；不能复用旧Full32的生成分数替代新参考组，也不能重评旧199题来宣称改进。
